❓ How to Use

Follow these simple steps to create ILAW lesson plans quickly. This app is designed for teachers and can work offline or online.

📝 How to create a lesson plan

  1. Click Create Lesson Plan.
  2. Fill in the teacher, school, grade level, subject, competency, topic, objectives, materials, references, learner background, and classroom setup.
  3. Click Generate Lesson Plan.
  4. Edit the generated ILAW lesson plan directly in the output box.

💾 How to save outputs

  1. After generating and editing your lesson plan, click Save Lesson Plan.
  2. Go to Saved Lessons to view, load, edit, delete, copy, print, or download your saved lesson plans.
  3. Your saved lesson plans stay in the same browser even after refreshing the page.

🖨️ How to print

  1. Generate the lesson plan.
  2. Review and edit the output.
  3. Click Print.
  4. Choose your printer or save as PDF from your browser’s print window.

⬇️ How to download

  1. Click the download button after generating your output.
  2. The lesson plan downloads as a Word-style document file that can open in Microsoft Word or similar apps.

🌐 How to use offline

  1. Save this app as one HTML file on your computer or USB drive.
  2. Open the file using Chrome, Edge, Safari, or Firefox.
  3. No internet is needed because the app uses embedded HTML, CSS, JavaScript, and localStorage.
  4. You can also upload the same HTML file to a website or hosting platform for online access.
